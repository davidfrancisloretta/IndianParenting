# Product Plan

## Locked Decisions

- Multi-family SaaS-ready.
- Initial test family has Isaac and Nehemiah.
- Parent is the only authenticated user for now.
- Parent switches between child profiles.
- All default chores apply to both children.
- Parent can add custom chores.
- `1 point = ₹1`.
- Only approved chores count toward payout.

## MVP

- Parent dashboard
- Child profile dashboard
- Daily chore generation
- Chore submission
- Parent approval and rejection
- Weekly payout estimate
- Custom family chores
- Leaderboard

## Follow-up Phases

1. Child PIN mode.
2. Streak engine with Redis cache.
3. Notification jobs for morning and bedtime reminders.
4. Weekly PDF report.
5. Family invite and subscription billing.
